# Tiny In-Memory Task API

A beginner backend project built using FastAPI to understand CRUD operations, request lifecycle, routing, and backend workflow fundamentals.

This project uses in-memory storage instead of a database to focus on understanding how backend systems process requests and modify application state.

---

## Features

- GET all tasks
- POST new tasks
- PUT update existing tasks
- DELETE tasks
- FastAPI route handling
- Path and query parameters
- JSON responses
- Basic backend request flow understanding

---

## Tech Stack

- Python
- FastAPI
- Uvicorn

---

## Project Goal

This project was built to:

- Understand FastAPI fundamentals
- Learn CRUD operations practically
- Understand backend request → response flow
- Practice Git + GitHub workflow through CLI
- Build confidence with Linux-based backend development
